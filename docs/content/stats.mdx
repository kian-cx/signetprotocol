# Site statistics

Anyone can see how many people read these docs. The numbers are public and updated every minute.

<VisitStats />

## How it is measured

- **No cookies and no personal data.** We store only aggregate counters: total views, views per day, per page and per country. No IP address, user agent or identifier is saved.
- **Unique browsers** is an approximation: the first time a browser visits, it leaves a flag in its own local storage. It counts browsers, not people.
- Bots and crawlers are ignored. Browsers that send *Do Not Track* are not counted.
- The code is open: [`docs/api/visits.js`](https://github.com/signetprotocol/signet/blob/main/docs/api/visits.js).
